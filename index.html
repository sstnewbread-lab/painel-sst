Como manter o painel atualizado
  1. Atualização automática (Chrome ou Edge no computador): clique em Conectar planilha e escolha o arquivo Dashboard_KPIs_Seguranca_do_Trabalho.xlsx. Sempre que a planilha for salva, o painel se atualiza sozinho em até 30 segundos. Ao reabrir o painel, clique em Reconectar.
  2. Manual (qualquer navegador): clique em Abrir arquivo ou arraste a planilha para dentro desta página.
  3. O painel lembra os últimos dados carregados neste computador. Nada é enviado para a internet: a leitura é feita no próprio navegador.
  4. Online: clique em ☁ Online para publicar o painel num link fixo que se atualiza sozinho.
  5. Para a diretoria (arquivo): com os dados atualizados, clique em Gerar versão diretoria. Será baixado um arquivo HTML só de leitura, com os dados daquele momento e sem nenhum acesso à planilha. Envie esse arquivo (e-mail, Teams, pasta compartilhada) sempre que quiser publicar uma nova atualização.
☁ Publicação online (GitHub Pages) – a diretoria abre sempre o mesmo link; o painel publica sozinho quando a planilha muda.
Preencha os 3 campos. Eles ficam guardados só neste computador.
